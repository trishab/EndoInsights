# Archive — August 2024 Analysis

These are the original charts generated from the August 2024 analysis of PubMed publication data.

## Preserved files

- **`PubmedEndoResearchPub.png`** — Publication timeline comparing endometriosis and IPF research volumes over time.
- `diff_IPF_Endo_Analysis.png` — Not recoverable; this file was not preserved on disk.

## Original findings (August 2024)

Cumulative totals as shown in the charts, based on bulk MEDLINE files downloaded from PubMed:

| Category | Count |
|---|---|
| All Endometriosis Studies | 34,241 |
| Genetic Mechanisms of Endometriosis | 977 |
| All IPF Studies | 9,596 |
| Genetic Mechanisms of IPF | 667 |

## Why these numbers differ from the current dataset

See the **A Note on Methodology and Data Versions** section in the main README for a full explanation.
In short: the original data came from a one-off bulk MEDLINE export with no recorded search terms. The current
dataset is fetched reproducibly via the PubMed E-utilities API with documented queries.
